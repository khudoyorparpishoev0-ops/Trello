# Короткая регрессия (после любого изменения)

Автоматически — 3 команды, около минуты:

```bash
npm run verify     # линтер + типы + 130 тестов + production-сборка
npm run test:e2e   # 44 сценария в браузере
```

Вручную — 7 пунктов, около 5 минут:

- [ ] Доска открывается, карточки видны, коды задач **не повторяются**
- [ ] Карточка создаётся (Enter) и встаёт в начало списка
- [ ] Панель задачи: меняются приоритет и срок, работает чек-лист, отправляется сообщение
- [ ] Переключение «Доска → Таймлайн → Таблица» показывает одни и те же задачи
- [ ] Поиск и фильтры «Мои карточки» / «Просрочено» отсекают задачи
- [ ] Дашборд: числа KPI совпадают с доской, архивные задачи не в «Активных»
- [ ] Телефон (390 px): нет горизонтальной прокрутки, таб-бар работает, попап срока помещается

После изменений на сервере дополнительно:

- [ ] `docker compose ps` — все сервисы `running`
- [ ] `curl -s localhost/api/health` — `"status":"ok"`
- [ ] Вход выполняется, после перезагрузки страницы сессия сохраняется
- [ ] Изменение сохраняется: правка → обновить страницу → правка на месте
