## Проверено и дефектов не найдено

- **XSS.** `dangerouslySetInnerHTML`, `eval`, прямая запись `innerHTML` в коде отсутствуют; React экранирует вывод. E2E-проверка: `<img src=x onerror=…>` в названии задачи не исполняется и не превращается в разметку.
- **SQL-инъекции.** Все запросы параметризованы (`$1, $2 …`), конкатенации пользовательского ввода в SQL нет.
- **Повышение привилегий через API.** Роль вычисляется на сервере при регистрации; эндпоинт профиля обновляет только белый список полей; передать `role` в запросе нельзя.
- **IDOR.** Операции над своими данными используют идентификатор из сессии, а не из тела запроса. Сброс чужого пароля закрыт проверкой роли администратора.
- **Секреты в репозитории.** Не найдены. `.gitignore` исключает `.env`, в `.env.example` только placeholder'ы.
- **Кодировка.** UTF-8 сквозной: `<meta charset>`, `Content-Type: application/json; charset=utf-8`, PostgreSQL. Символов `�` в интерфейсе нет.
- **Часовой пояс UTC+5.** Дата «6 авг 18:00» сохраняется и отображается без сдвига; Telegram-уведомления пересчитываются в Asia/Tashkent.
- **Математика чек-листа.** 5 из 8 → 63% (округление), деления на ноль нет, значение не превышает 100%.
- **Адаптивность.** На 320/390/768/1440 px горизонтального переполнения нет.
